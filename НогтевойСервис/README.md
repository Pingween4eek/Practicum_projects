## Ногтевой сервис
# Что это за проект?
«Ногтевой сервис» — это конфигурация для платформы 1С:Предприятие, разработанная для салонов ногтевого сервиса. Программа помогает вести повседневный учёт бизнеса: от закупки материалов до расчёта зарплаты и формирования отчётов.

# Какая цель у проекта?
Основная цель — дать владельцу ногтевой студии простой и надёжный инструмент для контроля бизнеса, чтобы видеть всю картину в одной системе.

# Какие данные обрабатывает система?
В основе конфигурации лежат данные о:
- товарах и материалах, их поступлениях от поставщиков и расходах в процессе работы
- складских остатках, сколько и каких товаров и материалов есть в наличии на данный момент
- движении денег, приходах от клиентов, расходах на закупки, зарплату
- бухгалтерских операциях

 # Как запустить проект?
 1. Загрузить конфигурацию из файла НогтевойСервис.dt в программе 1С:Предприятие 8.3
 2. Ввести данные пользователя (по умолчанию пользователь Администратор, без пароля)
 3. Начать отладку
